1. Entry & authentication

  • Email / password fields, show-password toggle, "Remember me"

4. Outages & faults — GPL Outages and Faults.dc.html

  • "What is happening now" — active outage cards with tap-to-open detail sheet
  • Your outage reports — status list
  • History — past outage/report log
  • Outage map — geographic view of affected zones, pin detail panel (GPL Outage Map.dc.html)

↳ Report a problem — GPL Report an Issue.dc.html, embedded

  • Step 1 — choose a category (with info popover on hidden categories)
  • Step 2 — describe the issue
  • Known-outage check — matches an existing report
  • Report linked confirmation, or Step 4 — details
  • Confirmation screen with reference number
  • Track — case status, back into "Your outage reports"

5. My services — GPL Service Requests.dc.html

  • "Which service do you need?" — service catalogue (3 families)
  • Service category — family drill-down with progress stepper
  • Guided request form — multi-step intake (new connection, billing query, meter/prepaid problem, etc.)
  • My requests — track open/closed cases, case reference & status
  • FAQ — searchable help articles

10. Help & global features

  • Help chat — floating launcher available on every screen (GPL Help Chat.dc.html)
  • Real navigation history — back chevron returns to the true previous page; hidden on main footer pages (Dashboard, Outages, Services, Menu), shown only on sub-pages
  • Bottom sheets — scrim + drag handle, no close button, auto-scaled to fit viewport
