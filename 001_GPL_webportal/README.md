# GPL Customer Web Portal — project folder (V1.3)

Exported from the GPL Portal_V1.3 Claude Design project.

## Open these first
- `downloads/GPL-Customer-Portal-Prototype-Standalone.html` — the full click-through prototype in one file. Works offline. Open it in Chrome, Edge, Safari or Firefox (not in a preview window).
- `downloads/GPL-Web-Portal-Developer-Handoff-Guide.html` — the developer handoff guide in one file. Works offline.
- `GPL Portal.html` — the bundled prototype. It loads the outage map and images from the files next to it, so keep it inside this folder.

## Folders
- `*.dc.html` — design-editor source pages (Login, Registration, OTP, Dashboard, Bills, Consumption, Service Requests, Report an Issue, Help Chat and others). They need the design editor runtime and won't display properly if opened directly.
- `_ds/` — Guyana Government Design System (tokens, styles, component bundle).
- `assets/` — logos, the sample bill, Inter fonts and the handoff-guide screenshots (`assets/handoff-web/`).
- `uploads/` — discovery notes, requirements, transcripts, the routing matrix and reference images.
- `compat.json` — the project's page list.
