# GPL Designs

Design output for Guyana Power & Light (GPL), prepared by EK Digital.

| Folder | What it holds |
|---|---|
| `001_GPL_webportal/` | GPL Customer Web Portal design files |
| `002_GPL_Mobile_APP/` | GPL Portal Mobile app: `GPL_Portal_Mobile_V1.3/` (full project, prototype, developer handoff guide) and `gpl-dashboard-incidents-outages/` (SKILL.md for the Dashboard and Incidents & outages screens) |

- Project details: `002_GPL_Mobile_APP/GPL_Portal_Mobile_V1.3/README.txt`
